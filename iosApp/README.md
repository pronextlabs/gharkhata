# GharKhata iOS Application

Native iOS implementation of **GharKhata** built with **SwiftUI** and targeted for **iOS 16.0+**.

---

## Architecture

- **UI Framework**: SwiftUI (declarative, minimal-text ergonomics)
- **Design System**: Warm Terracotta & Bone White palette matching Android Material 3 design tokens
- **Persistence**: 100% Offline CoreData / Local JSON store with zero network dependencies
- **Auto-Calculators**: Direct Swift parity with Kotlin calculation algorithms (Daily Safe Spend, Milk Bottle Tally, Staff Payroll)
- **Haptics**: `UIImpactFeedbackGenerator` providing crisp tactile clicks on keypad buttons
- **Security**: LocalAuthentication (Face ID / Touch ID) for Gupt Tijori
